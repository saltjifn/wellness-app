# ИИ на телефоне: два варианта

## Вариант 1 — Без сервера и без Render (проще всего)

Приложение само дергает OpenRouter. Ключ кладётся в сборку (в APK), поэтому **не выкладывай приложение в сторе и не раздавай APK** посторонним — иначе ключ могут вытащить.

1. В корне проекта создай **`.env`** и добавь (подставь свой ключ с https://openrouter.ai):
   ```env
   VITE_OPENROUTER_API_KEY=sk-or-v1-твой-ключ
   ```
2. Собери и установи на телефон:
   ```powershell
   npm run build
   npx cap sync android
   npx cap open android
   ```
   В Android Studio: **Build** → **Build APK(s)**. Ставишь APK на телефон — ИИ работает, без всякого Render.

---

## Вариант 2 — С сервером (Render и т.п.)

Если хочешь, чтобы ключ не лежал в приложении, выкладываешь сервер (например на Render), в приложении указываешь `VITE_WELLNESS_API_URL=https://твой-сервис.onrender.com` и собираешь. Подробности можно глянуть в истории этого файла или в .env.example.
